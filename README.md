# IBM Employee Attrition Analysis using R

## Overview
This project analyzes the IBM Employee Attrition dataset using R. It includes data loading, data quality assessment, descriptive statistics, data visualization, outlier detection, and correlation analysis to understand employee attrition patterns.

## Features
- Data Loading and Inspection
- Data Quality Assessment
- Descriptive Statistics
- Univariate Analysis
- Outlier Detection
- Bivariate Analysis
- Correlation Analysis

## Technologies Used
- R Programming
- Base R
- ggplot2
- dplyr

## Dataset
IBM Employee Attrition Dataset (IBM.csv)

## Project Structure
```
IBM-Employee-Attrition-R/
│── IBM.csv
│── analysis.R
│── README.md
```

## How to Run
1. Install R and RStudio (or use VS Code with R).
2. Open `analysis.R`.
3. Place `IBM.csv` in the project folder.
4. Run the script to generate the analysis and visualizations.

## Output
The project generates:
- Summary statistics
- Histograms
- Bar charts
- Boxplots
- Scatter plots
- Correlation matrix
- Employee attrition insights
